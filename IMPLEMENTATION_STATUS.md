## 📋 How to Use This Framework

### **For New Projects**

1. **Clone the framework**
   ```bash
   git clone https://github.com/bestfinderai-hub/aibos-master-framework.git
   cd aibos-master-framework
   git checkout -b my-project
   ```

2. **Customize**
   - Copy DEL 19 prompt for your specific project
   - Create `.claude/projects/my-project.md` with requirements
   - Modify `src/modules/` to match your needs

3. **Start building**
   - Follow DEL 6 (Development Workflow)
   - Use the 5 Universal Skills (Kontrollant, Psykolog, etc)
   - Commit frequently to main branch
   - Document decisions in DECISION_LOG.md

### **For Existing Projects**

1. **Adopt the structure**
   - Move code into DEL-aligned directories
   - Document existing features using DEL framework
   - Migrate to AIBOS Code Standard (DEL 6)

2. **Add skills**
   - Copy 5 universal skills to `.claude/skills/universal/`
   - Create project-specific skills in `.claude/skills/[project]/`

3. **Document**
   - Create `docs/architecture/PROJECT_OVERVIEW.md`
   - Document key decisions
   - Link to relevant DELs

## 🎯 Key Principles to Remember

1. **Customer First** — Build what customers need, not what's technically interesting
2. **Simple > Complex** — Simplest solution that meets requirements
3. **Reuse > Rebuild** — Check if solution exists before building
4. **Document > Code** — If it's not documented, it doesn't exist
5. **Test > Deploy** — All tests must pass before production
6. **Measure > Guess** — All decisions based on data
7. **AI > Manual** — Automate repetitive work
8. **Secure > Convenient** — Security gates all releases
