# DEL 21 — Universal Plugin Platform

## 🔌 Vision

Core Platform stays SMALL & STABLE.
All features installable as plugins.

## Plugin Types

1. **Modules** (big features)
   - Lead Intelligence, CRM, Marketing
   - Can be enabled/disabled per customer

2. **Integrations** (connect to other services)
   - Stripe, Slack, Zapier, etc

3. **Custom** (build your own)
   - White-label features
   - Custom workflows

## Plugin Marketplace

Future: Plugin store where developers sell plugins.
